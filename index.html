Installation & Setup Guide

Deploy TraceGuard globally across developer machines, inside project repositories, or as an automated pull-request gate in your CI/CD pipelines.

Package Manager: 
npm install -g @arnavvv/traceguard
✓ Runtime Requirements
Requires Node.js >= 20.18.0 (LTS). Verified on Node 20, 22, and 24 across Windows, macOS, and Linux.
✓ Zero Native Dependencies
Pure TypeScript compiled to ESM and CJS. Uses standard Fetch API and Node builtins. Zero external system binaries.
✓ 100% Offline & Private
Operates entirely locally with zero telemetry, zero analytics, zero external network calls, and no cloud accounts.
The Real-World Problem

How TraceGuard Catches Breaking Changes

Consider an API contract declaring GET /api/users/{id} returning { id: string, name: string, email: string }. When the backend inadvertently returns an integer id: 101 and drops email, TraceGuard catches it at the CI gate:

fixtures/central-example/spec-v1.yaml OpenAPI 3.1 
paths:
  /api/users/{id}:
    get:
      responses:
        '200':
          content:
            application/json:
              schema:
                type: object
                required: [id, name, email]
                properties:
                  id: { type: string }
                  name: { type: string }
                  email: { type: string }
Observed API Response CONTRACT DRIFT 
{
  "id": 101,          // ERROR: expected string
  "name": "Arnav"     // ERROR: email missing
}
Core Capabilities

Engineered for High-Stakes CI Pipelines

🛡️

Runtime Contract Verification

Validates actual responses from running microservices against OpenAPI 3.0.x and 3.1.x specifications. Validates HTTP status codes, headers, and payload structures.

⚡

Direction-Aware Compatibility Diff

Differentiates request vs response direction. Correctly flags enum narrowing on responses as breaking, while safely tolerating optional parameter expansion on requests.

📁

Baseline Snapshot Quarantine

Record existing legacy contract mismatches into an audited .traceguard-baseline.json snapshot. Only newly introduced breaking changes fail your PR builds.

🔒

Adversarially Hardened

Built under hostile-input assumptions: automatic masking of canary secrets, ReDoS catastrophic regex defenses, prototype-pollution blocks, and manual redirect SSRF prevention.

📊

Multi-Format Reporting

Outputs beautifully styled terminal dashboards, GitHub Flavored Markdown for automated PR sticky comments, clean JSON for telemetry, and standalone HTML reports.

📦

Dual CLI & TypeScript SDK

Run traceguard directly in terminal and CI runners, or import createTraceGuard() and compareContracts() into Vitest, Jest, or custom test suites.
